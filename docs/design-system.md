| 항목 | Somenail | 공용 규약 위치 |

| 동작색 | 매트 그린 `#16744E` | §2 |

### 왜 이렇게 정했나

- **무채색 크롬.** Somenail은 사용자가 색을 고르는 도구다. 이전 크롬(#10131A 등)은 푸른빛이 돌아 사용자의 배경색이 실제와 다르게 보였다. 회색은 R≈G≈B로 맞췄다.
- **녹색 동작색.** 배경·글자 프리셋 20색 어디에도 없는 색이라 캔버스 위 선택 표시와 사용자 색이 헷갈리지 않는다. 커팅 매트의 색이기도 하다.
- **살구색은 로고로만.** 이전에는 살구색 계열 25가지 HEX가 버튼·선택·포커스·번호·제목에 흩어져 있었다. 이제 제품을 알아보게 하는 로고에만 남기고, 동작은 녹색이 맡는다(공용 §2).
- **밝은 기본값.** 주 사용자는 블로그·SNS 작성자다. 같은 패밀리의 어디서?, msalt.net도 밝은 종이 표면이다.

대담한 요소는 **매트 격자**와 **잘린 모서리 로고** 두 곳뿐이다. 나머지는 조용하게 둔다.

### 2.3 캔버스 토큰 (`src/design/tokens.ts`)

Konva는 CSS 변수를 읽지 못하므로 상수로 둔다.

- 선택 테두리: 녹색 `#1E8A5E` 2px **+ 흰 할로**. 한 가지 색으로는 모든 배경에서 보일 수 없기 때문이다(녹색도 코발트 #4069DB 위에서는 1.14:1).
- 핸들: 흰 채움 + 녹색 외곽선 + 어두운 그림자.
- 굵기와 핸들 크기를 보기 배율로 나눠 **화면에서 항상 같은 크기**로 보이게 한다.
- 선택 레이어는 PNG 내보내기 때 숨긴다(기존 동작).
- 사용자 색 프리셋(`src/editor/palette.ts`)은 UI 토큰이 아니다. 선택색이 프리셋과 같아지지 않는지 테스트로 확인한다.

### 2.4 캔버스 글꼴 (`src/editor/fonts.ts`, `fontFaces.ts`)

사용자가 고르는 출력물 글꼴이다. UI 토큰이 아니며, 썸네일 제목에 쓰기 좋은 **서로 다른 인상**을 기준으로 골랐다.

| 묶음 | 글꼴 | 굵게 |
| --- | --- | --- |
| 고딕 | **프리텐다드 Pretendard(새 텍스트 기본값)** · 본고딕 Noto Sans KR · 나눔고딕 Nanum Gothic · IBM 플렉스 IBM Plex Sans KR · 고운돋움 Gowun Dodum · 도현 Do Hyeon · 주아 Jua · 동글 Dongle | 프리텐다드·본고딕·나눔고딕·IBM 플렉스·동글 |
| 명조 | 본명조 Noto Serif KR · 나눔명조 Nanum Myeongjo · 함렛 Hahmlet · 고운바탕 Gowun Batang | 전부 |
| 제목용 | 검은고딕 Black Han Sans · 스타일리시 Stylish | — |
| 손글씨 | 나눔손글씨 펜 Nanum Pen Script · 나눔손글씨 붓 Nanum Brush Script · 독도 Dokdo | — |

- **시스템 글꼴을 쓰지 않는다(v1.4).** v1.3까지의 "기본" 묶음(고딕·명조·모노)은 `Arial, Apple SD Gothic Neo, Malgun Gothic` 같은 OS 글꼴 스택이라 Windows에서는 맑은 고딕, macOS에서는 애플 SD 산돌고딕 Neo로 그려져 같은 작업의 PNG가 기기마다 달랐다. 모두 웹폰트로 바꿔 어디서나 같은 결과가 나오게 했다. 작업은 저장되지 않으므로 옛 값을 옮길 일은 없다.
- **Pretendard는 UI와 같은 파일.** `main.tsx`에서 UI용으로 이미 불러오는 `pretendard` 가변 글꼴(동적 서브셋)을 캔버스에도 쓴다. 굵기 45~920이 있어 굵게가 진짜 굵기로 그려진다.

- **직접 호스팅.** npm `@fontsource/*`·`pretendard`(OFL-1.1)로 번들한다. Google 서버에 요청하지 않는다(공용 §4 글꼴 로딩, TRD 서드파티 요청 없음).
- **필요한 글자만 내려받는다.** 한글 글꼴은 `unicode-range`로 100여 조각으로 나뉘어 있고, 브라우저는 화면에 쓰인 글자가 든 조각만 받는다. 캔버스는 이 다운로드를 스스로 일으키지 않으므로 글자·글꼴·굵기가 바뀔 때마다 `document.fonts.load()`로 받은 뒤 Konva 텍스트를 다시 재고 그린다. PNG 다운로드 직전에도 모든 텍스트에 대해 같은 확인을 한다.
- **굵기가 하나뿐인 글꼴은 굵게를 끈다.** 브라우저가 가짜 굵기를 덧칠하면 획이 뭉개진다. 해당 글꼴을 고르면 굵게 버튼은 비활성("이 글꼴은 굵기가 하나예요")이고, 다시 굵기가 있는 글꼴로 바꾸면 사용자가 켜 둔 굵게가 돌아온다.
- **글꼴 이름 미리보기 배율.** 동글·손글씨처럼 같은 크기에서 글자 면이 작은 글꼴은 드롭다운에서만 `previewScale`(1.1~1.6)로 키워 이름이 읽히게 한다. 캔버스 출력에는 영향이 없다.
- 목록·`@font-face` 가져오기·굵기 표시가 서로 맞는지 `fonts.test.ts`로 확인한다.

### 3.1 간결한 컨트롤 원칙 (v1.2)

- **맥락이 말해주는 라벨은 보이지 않게 한다.** "배경" 패널의 "배경색", 텍스트 패널의 "내용·크기·글꼴·글자색"처럼 패널 제목·단위(px, °)·컨트롤 모양으로 이미 드러나는 라벨은 `hideLabel`/`hideLegend`로 보조기기에만 남긴다.
- **관습이 있는 선택은 아이콘만.** 정렬, 레이어 순서, 굵게, 삭제, 닫기. 아이콘만 쓰는 컨트롤은 접근 이름과 `title` 툴팁이 반드시 있다.
- **관습이 약한 아이콘 그룹은 범례를 보인다.** 테두리 스타일은 아이콘이 결과를 묘사(선 모양)할 뿐 무엇을 고르는지는 말하지 않으므로 "테두리" 범례를 보인다(v1.3). v1.2의 "같은 하트에 테두리만 바꾼" 아이콘은 16px에서 차이가 읽히지 않아 버렸다.
- **고른 항목은 채움으로만 표시한다(v1.4).** 세그먼트·토글(굵게)·드롭다운 옵션은 `--color-selected` 배경 + `--color-on-selected` 글자로 고른 상태를 보인다. 컨트롤에는 이미 테두리가 있으므로 고른 항목에 테두리·안쪽 링을 더하지 않는다(겹친 두 줄로 보인다). 예외: 색 견본은 채움 자체가 사용자 색이라 바깥 링으로 표시한다.
- **브라우저 기본 외관을 쓰지 않는다.** 선택지가 2~4개면 세그먼트, 5개 이상이면 시스템이 그린 `Select`(글꼴). 숫자는 `NumberField`, 슬라이더와 스크롤바는 시스템 스타일. 색 피커 팝업만 네이티브(색 상자는 시스템이 그린다).
- **같은 상태 변화로 배치가 흔들리지 않게 한다.** 사이드바는 `scrollbar-gutter: stable`로 스크롤바 자리를 항상 비워 둔다. 컨트롤이 나타나도 폭이 바뀌지 않는다.
- **도움말은 동작을 바꿀 때만.** 회전 핸들·윤곽 방식 설명처럼 결과를 보면 아는 안내는 두지 않는다.

## 4. 레이아웃

```text
┌───────────────────────────────────────────────────────────────────┐
│ [s] somenail.                                    [↓ PNG 다운로드] │ 56
├────────────────────┬──────────────────────────────────────────────┤
│ 배경                │ 1280 × 720 px                      보기 81% │
│ [■][#111827]  ●●●●● │ ┼───┼───┼───┼── 커팅 매트 ──┼───┼───┼───┼ │
│ ────────────────── │     ┌──────────────────────────────┐        │
│ 추가                │     │          캔버스(종이)          │        │
│ [▣ 이미지][T 텍스트] │     └──────────────────────────────┘        │
│ ────────────────── │       Delete 삭제 · Esc 선택 해제            │
│ T 텍스트 ⧉ ⧉ 🗑 │ × │                                            │
│ [내용             ] │                                            │
│ [고딕         ⌄] [B] │                                            │
│ [− 88 px +] [≡|≡|≡] │                                            │
│ [■][#FFFFFF]  ●●●●● │                                            │
│ 🔒 브라우저 안에서만 │                                            │
└────────────────────┴──────────────────────────────────────────────┘
```

- 사이드바 순서: **배경 → 추가 → 선택한 요소 → 안내**. 항상 있는 패널을 위에, 선택할 때만 나타나는 패널을 아래에 둔다. 선택 패널이 나타나고 사라져도 위쪽 패널은 움직이지 않는다.
- 선택한 요소 패널의 머리줄: 아이콘 · 제목 · **뒤로 보내기 · 앞으로 가져오기 · 삭제 | 선택 해제**(모두 아이콘). 맨 뒤/맨 앞이면 해당 버튼은 비활성.
- 이미지 패널: [각도 아이콘] 슬라이더 [0 °] [초기화] → "테두리" 범례 + 세그먼트(⊘ · ─ · 지그재그) → 테두리가 있을 때만 [두께 아이콘] 슬라이더 12px · 색.
- 모바일(≤ 800px): 캔버스 → **선택한 요소** → 배경 → 추가 → 안내. 캔버스를 만진 직후 바로 아래에서 속성을 바꾼다.
- 패널은 그림자 없이 구분선으로 나눈다. 번호(01·02·03)를 붙이지 않는다 — 순서가 정해진 과정이 아니다.
- 글자와 컨트롤은 왼쪽 정렬, 캔버스 아래 힌트만 가운데 정렬.
- 출력 크기·보기 배율 줄과 캔버스 힌트는 **캔버스(종이) 폭에 맞춘다**. 보기 배율은 작업 공간의 실제 안쪽 폭(토큰 여백 제외)으로 계산한다.
- 키보드 힌트(`Delete` 삭제 · `Esc` 선택 해제)는 터치 기기(`pointer: coarse`)에서 숨긴다.
- 한글은 어절 단위로 줄을 바꾼다(`word-break: keep-all`). "됩/니다"처럼 음절 중간에서 끊지 않는다.
- 사이드바는 오른쪽 안쪽 여백을 `--space-3`으로 줄여, 항상 비워 둔 스크롤바 자리와 합쳐 왼쪽 `--space-5`와 비슷하게 보이게 한다.

## 5. 문구

공용 §6.1을 따른다. Somenail의 고정 문구:

| 상황 | 문구 |
| --- | --- |
| 주요 동작 / 진행 중 | PNG 다운로드 / PNG 만드는 중… |
| 다운로드 시작 (`role="status"`, 화면에는 보이지 않음) | PNG 다운로드를 시작했어요. |
| 추가 | 이미지 · 텍스트 |
| 빈 캔버스 | 이미지나 텍스트를 추가해 시작하세요. |
| 요소가 있을 때 | `Delete` 삭제 · `Esc` 선택 해제 |
| 레이어 (아이콘 툴팁) | 뒤로 보내기 · 앞으로 가져오기 · 삭제 (Delete) · 선택 해제 (Esc) |
| 정렬·테두리 (아이콘 툴팁) | 왼쪽/가운데/오른쪽 정렬 · 테두리 없음 · 깔끔한 테두리 · 종이 컷아웃 테두리 |
| 굵게 (툴팁) | 굵게 · 굵기가 하나뿐인 글꼴에서 "이 글꼴은 굵기가 하나예요"(비활성) |
| 글꼴 묶음 | 고딕 · 명조 · 제목용 · 손글씨 |
| HEX 오류 | #RRGGBB 형식의 6자리 HEX로 입력하세요. |
| 개인정보 안내 | 이미지는 이 브라우저 안에서만 처리돼요. 새로고침하면 작업이 사라집니다. |

## 6. 일관성 검사

`src/design/tokens.test.ts` (`npm test`에 포함):

1. 공용 규약 §3.2의 필수 토큰이 모두 정의돼 있다.
2. 글자 4.5:1, 비텍스트(입력 경계·동작색·포커스) 3:1 대비를 만족한다.
3. 캔버스 선택색(`tokens.ts`)이 `tokens.css`의 값과 같고, 배경 프리셋과 겹치지 않는다.
4. `tokens.css` 밖의 CSS와 `src/ui/*.tsx`에 HEX·`rgb()`·`hsl()`이 없다.
5. `font-size`, `font-weight`, `border-radius`, `z-index`는 토큰(`var(--…)`)으로만 지정한다.
6. 포커스 링은 `2px solid var(--color-focus)`, `outline-offset`은 2px(작업 공간 안쪽 표시만 -2px)로 공용 §4와 같다.

### 변경 절차

1. 기존 토큰으로 해결되는지 먼저 확인한다.
2. 새 토큰이 필요하면 `tokens.css`와 이 문서 §2를 같은 PR에서 고친다.
3. 공용 이름의 의미를 바꿔야 하면 msalt-studio 공용 문서를 먼저 고친다.
4. PR 체크리스트: 원시 값 없음 · `src/ui/` 컴포넌트 사용 · 동작색은 동작·선택에만 · 키보드 포커스 · 390px 폭 확인 · 문구 규칙.
