# PRD — Somenail 제품 요구사항

- **제품명:** Somenail (썸네일)
- **문서 상태:** Draft / MVP 기준
- **작성일:** 2026-11-10
- **관련 문서:** [README](../README.md) · [TRD](TRD.md)

## 1. 문제와 목표

### 문제
블로그·SNS·영상용 간단한 썸네일을 만들기 위해 종합 디자인 도구를 열면, 템플릿 선택과 불필요한 패널 탐색에 시간을 쓰기 쉽습니다.

### 목표
사용자가 **배경색 → 이미지 업로드 → 텍스트 입력 → PNG 저장** 과정을 별도 학습 없이 한 화면에서 끝낼 수 있게 합니다.

### 비목표
범용 그래픽 편집기, 템플릿 마켓플레이스, AI 디자인 서비스, 크리에이터 협업 플랫폼을 만드는 것은 목적이 아닙니다.

## 2. 사용자 및 대표 시나리오

- 블로그나 기술 글의 대표 이미지를 빠르게 제작하는 작성자
- 유튜브/SNS의 간단한 커버 이미지를 만드는 사용자
- 이미 준비한 사진·제품 이미지를 배경색·제목과 조합하는 사용자

**기본 시나리오:** 사용자는 사이트에 접속해 배경을 검정색으로 바꾸고, 투명 PNG 오브젝트를 올린 뒤 오른쪽으로 이동합니다. 왼쪽에 분홍색 굵은 제목을 입력하고 PNG를 다운로드합니다.

## 3. UX 원칙

1. **처음부터 편집:** 홈/온보딩/로그인 없이 곧바로 편집기 표시
2. **핵심 3영역:** 배경 · 이미지 · 텍스트 외의 메뉴는 최소화
3. **즉시 미리보기:** 속성 수정과 드래그 결과를 바로 반영
4. **WYSIWYG:** 화면에 보이는 배치가 출력 파일에도 재현
5. **데이터 로컬 처리:** 입력 이미지는 서버로 업로드하지 않음

### 화면 구성 (데스크톱 기준)

- 상단: 제품명, **PNG 다운로드** 버튼
- 편집 패널: 배경색 / 이미지 추가 / 텍스트 추가 및 선택한 요소 속성
- 메인: 16:9 캔버스, 오브젝트 클릭 선택·드래그·크기 조절
- 빈 캔버스에서도 즉시 사용 가능; 불필요한 모달 없음

작은 화면에서는 패널과 캔버스를 세로 배치합니다. 모바일 고급 편집 최적화는 추후 개선합니다.

## 4. MVP 기능 요구사항

| ID | 우선순위 | 요구사항 | 완료 기준 |
| --- | --- | --- | --- |
| FR-01 | 필수 | 1280×720, 16:9 캔버스 제공 | 진입 즉시 빈 캔버스 렌더링 |
| FR-02 | 필수 | 배경색 컬러 피커 + HEX 입력 | 유효한 색상 입력 즉시 반영 |
| FR-03 | 필수 | 로컬 PNG/JPEG/WebP 오브젝트 업로드 | 선택한 이미지가 캔버스에 추가됨 |
| FR-04 | 필수 | 이미지 선택·드래그·크기 조절·삭제 | 여러 이미지의 위치/크기 개별 편집 가능 |
| FR-05 | 필수 | 텍스트 입력·수정·여러 줄 | 한글 포함, 여러 텍스트 블록 추가 가능 |
| FR-06 | 필수 | 텍스트 크기·굵기·색상·정렬 및 위치 | 스타일 변경이 즉시 적용됨 |
| FR-07 | 필수 | 캔버스 내 요소의 겹침 순서 | 추가 순서 기준으로 쌓이고, 선택한 요소를 앞/뒤로 이동 가능 |
| FR-08 | 필수 | PNG 다운로드 | 정확히 1280×720, 워터마크 없음 |
| FR-09 | 필수 | 잘못된 이미지/색상 입력 처리 | 오류를 보여주고 편집기 상태는 유지 |
| FR-10 | 필수 | 업로드 파일의 브라우저 내부 처리 | 이미지 업로드 API 호출 없음 |

**이미지 배치:** 삽입 직후 화면 안에 들어오도록 비율을 유지하며 적절한 크기로 중앙 배치합니다. 변형 중에도 종횡비 유지를 기본으로 합니다.

**텍스트 기본값:** 읽기 쉬운 시스템/오픈 라이선스 한글 글꼴, 검정 텍스트와 충분한 기본 글자 크기를 제공합니다. 줄바꿈은 명시적 개행을 유지합니다.

**파일 정책:** 1개 이미지당 20MB 이하를 초기 한도로 제안합니다. 형식 및 디코딩을 검증하고 지원하지 않는 파일은 안내 후 거절합니다. URL을 통한 외부 이미지 불러오기는 MVP에 포함하지 않습니다.

## 5. 범위 밖 (MVP 제외)

- AI 생성, 배경 제거, 이미지 필터, 사진 소재 라이브러리
- 사전 제작 템플릿, 스티커 팩, 복잡한 도형/벡터 편집
- 클라우드 저장, 로그인, 사용자 계정, 동기화, 협업
- JSON 프로젝트 저장/불러오기 및 자동 복구
- 실행 취소/다시 실행, 키보드 단축키, 정렬 가이드/스냅
- 다중 캔버스 크기, JPEG/WebP 내보내기, 여러 파일 일괄 처리
- 모바일 전용 편집 제스처의 고급 최적화

선정 기준은 **기능 수가 아닌 편집 완료까지의 조작 수**입니다.

## 6. 비기능 요구사항

- **개인정보:** 이미지 파일과 텍스트를 외부 API에 보내지 않음; 서버 저장 없음
- **운영:** 백엔드 서버·DB·비밀 API 키 없이 정적 배포 가능
- **호환성:** 최신 Chrome/Edge/Safari의 일반적인 데스크톱 환경 우선
- **안정성:** 무효 파일, 디코딩 실패, 이미지 내보내기 실패 시 사용자에게 오류 안내
- **사용성:** 편집기 첫 화면에 핵심 3기능과 다운로드가 모두 노출
- **접근성:** 입력 요소 레이블, 포커스 표시, 기본 키보드 탐색 제공

## 7. 성공 기준 및 검증

| 측정 항목 | MVP 목표 | 검증 방법 |
| --- | --- | --- |
| 첫 결과물 제작 | 신규 사용자가 60초 이내 기본 썸네일 제작을 시도할 수 있음 | 관찰형 사용성 테스트(목표, 실측 전) |
| 출력 크기 | 1280×720 픽셀 | 저장 파일의 픽셀 검사 |
| 데이터 처리 | 사용자 사진을 네트워크로 전송하지 않음 | DevTools 네트워크 점검 |
| 기능 완결성 | 배경/이미지/텍스트 변경 후 다운로드 가능 | 수동 E2E 시나리오 |
| 편집 일관성 | 미리보기와 PNG의 구성·비율·색상 일치 | 샘플 이미지 육안 비교 |

### MVP 인수 시나리오

1. 기본 배경을 `#000000`으로 지정하면 화면과 PNG에 검정 배경이 적용된다.
2. 투명 PNG와 JPG 두 장을 추가하고 개별 이동·크기 변경·순서 조정·삭제가 가능하다.
3. 한글 여러 줄 제목을 추가하고 크기·굵기·색상·정렬을 수정할 수 있다.
4. 브라우저 편집 화면이 작아도 결과 PNG는 1280×720으로 출력된다.
5. 유효하지 않은 이미지나 HEX 코드는 편집기를 중단시키지 않는다.
6. 로그인·서버 업로드 없이 전체 플로우가 동작한다.

## 8. 구현 단계

- **Phase 1 — MVP:** 배경색, 이미지, 텍스트, 간단한 레이어 편집, PNG 출력
- **Phase 2 — 사용성 검증:** 실제 사용자가 어디서 막히는지 관찰하고 개선
- **Phase 3 — 선택적 확장:** 템플릿·다른 비율·로컬 프로젝트 저장 등 수요 검증 후 결정

> MVP의 제품적 차별화는 새로운 편집 기능이 아니라 **불필요한 선택을 없앤 빠른 작업 흐름**입니다.
