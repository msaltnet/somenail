### 잘 되어 있는 점 (유지)

- 키보드 포커스 링(`:focus-visible`)이 모든 입력 요소에 있음
- 스와치에 `aria-pressed`와 이름이 붙어 있음
- 작은 화면에서 캔버스를 먼저 보여주는 순서
- 이미지가 브라우저 밖으로 나가지 않는다는 안내

## 2. 개선 방향

### 원칙

1. **캔버스가 주인공이다.** 사용자의 결과물만 색을 가지고, 크롬(UI 외곽)은 무채색으로 물러난다. (D9)
2. **강조색은 한 가지, 의미도 한 가지.** 강조색은 "주요 동작"과 "현재 선택"에만 쓴다. 장식에는 쓰지 않는다. (D1, D7)
3. **지금 편집하는 것이 가장 가까이에 있다.** 선택한 요소의 속성은 스크롤 없이 보여야 한다. (D4)
4. **화면의 글자는 모두 일을 한다.** 장식용 라벨, 마케팅 문구, 의미 없는 번호를 없앤다. (D5, D6)
5. **모든 값은 토큰에서 온다.** 컴포넌트 CSS에 HEX와 임의 px 값을 쓰지 않는다. (D2)

### 2.1 시각 방향 — "커팅 매트 위의 종이" (권장안 A)

손그림 컷아웃(가위로 오린 종이) 기능이 Somenail만의 특징이라는 점에서 출발합니다.

- **작업 공간 = 커팅 매트.** 밝은 무채색 바탕에 아주 옅은 격자(24px 간격, 120px마다 진한 선). 캔버스는 그 위에 놓인 종이처럼 그림자를 받는다. 격자는 위치를 가늠하는 데도 쓰인다.
- **강조색 = 커팅 매트 그린.** 기존 피치색을 대체한다. 녹색은 썸네일 배경 프리셋과 겹치지 않고(피치 충돌 문제 해소), 흰 글자를 얹어도 5.77:1(AA)이 나온다.
- **크롬 = 밝은 무채색 기본, OS 다크 모드 지원.** 주 사용자는 디자이너가 아니라 블로그·SNS 작성자이므로 밝은 기본값이 더 친숙하다. 토큰 구조상 다크 테마는 값만 바꾸면 된다.
- **브랜드 마크.** "s." 정사각형 마크의 한 모서리를 사선으로 잘라 '오린 종이' 느낌을 준다. 대담한 요소는 이 마크와 매트 격자 두 곳으로 한정한다.

**대안 B — 기존 다크 + 피치 유지.** 브랜드 인상을 바꾸지 않고 정리만 한다. 피치를 한 값(`#F3AD93`)으로 통일하고, 크롬을 무채색 다크로 바꾸고, 선택 표시는 이중 외곽선으로 만든다. 2.2~2.5는 두 안에 똑같이 적용된다.

### 2.2 레이아웃

**데스크톱(≥ 801px)** — 기존 2열 구조는 유지하되 사이드바의 순서와 내용을 바꾼다.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [s.] somenail                                         [↓ PNG 다운로드] │ 56px
├──────────────────────┬───────────────────────────────────────────────┤
│ 추가                  │ 1280 × 720 px                        보기 65% │
│ [▣ 이미지] [T 텍스트]  │ ┌ · · · · · · · · · · · · · · · · · · · · ┐ │
│ PNG·JPG·WebP, 20MB    │ ·   ┌───────────────────────────────┐     · │
│ ───────────────────── │ ·   │                               │     · │
│ 텍스트          [×]   │ ·   │          (캔버스/종이)          │     · │
│  내용 / 크기 / 색      │ ·   │                               │     · │
│  글꼴 / 정렬 / 굵기    │ ·   └───────────────────────────────┘     · │
│  [뒤로] [앞으로] [삭제] │ ·     Delete 삭제 · Esc 선택 해제          · │
│ ───────────────────── │ └ · · · · · · · · · · · · · · · · · · · · ┘ │
│ 배경                  │                     커팅 매트 격자          │
│  [■] #111827          │                                             │
│  ● ● ● ● ●            │                                             │
│  ● ● ● ● ●            │                                             │
│ ───────────────────── │                                             │
│ 🔒 이미지는 이 브라우저 │                                             │
│ 안에서만 처리돼요       │                                             │
└──────────────────────┴───────────────────────────────────────────────┘
   320px
```

- **추가**(이미지·텍스트)를 맨 위에 두 개의 같은 크기 버튼으로 둔다.
- **선택한 요소 패널**은 '추가' 바로 아래에 나타난다 → 스크롤 없이 보인다. (D4)
- **배경**은 항상 아래에 보인다. 문서 전체의 속성이므로 고정 위치가 맞다.
- 히어로 문구, "CREATE SOMETHING", 작업 공간 푸터, 상단 "브라우저에서만 편집" 표시를 없앤다. 개인정보 안내는 사이드바 하단 한 곳에만 둔다. (D5)
- 01·02·03 번호 대신 아이콘 + 제목을 쓴다. (D6)
- 작업 공간 상단에는 출력 크기와 현재 보기 배율만 표시한다.

**모바일(≤ 800px)** — 캔버스 → 선택한 요소 패널 → 추가 → 배경 순서로 쌓는다. 캔버스를 조작한 직후 바로 아래에서 속성을 바꿀 수 있다. 터치 대상은 최소 44px로 한다.

### 2.3 컴포넌트 정리

버튼 7종을 **4가지 변형**으로 합친다(상세 규칙: design-system.md §3).

| 기존 | 변경 |
| --- | --- |
| export-button | `Button primary lg` — 화면에 하나만 |
| upload-button, add-text-button | `Button secondary lg` + 아이콘, 2열 그리드 |
| layer-actions(뒤로/앞으로) | `Button secondary sm` |
| layer-actions 삭제 | `Button danger-ghost sm` |
| reset-rotation, 선택 해제 × | `IconButton ghost` |
| outline-style-picker, toggle-bold, 정렬 select | `SegmentedControl` (정렬도 3개뿐이므로 세그먼트로) |

색상 입력은 **ColorField 하나**로 통일한다: 색 샘플(피커) + 편집 가능한 HEX 입력 + 선택적 스와치 그리드. 배경·글자·테두리 모두 같은 방식으로 조작한다. (D12)

### 2.4 캔버스 선택 표시 (버그 수정 포함)

선택 표시는 **어떤 배경에서도 보여야** 하므로 한 가지 색으로는 해결되지 않습니다. 계산해 보면 녹색 선택색도 코발트 배경(#4069DB)에서는 대비가 1.14:1밖에 안 됩니다.

- 테두리: **강조색 2px + 바깥쪽 1px 흰색 할로**(Konva Transformer의 `borderStroke` + 그림자/추가 Rect로 구현)
- 핸들: 흰 채움 + 강조색 외곽선 + 작은 어두운 그림자
- 값은 `src/design/tokens.ts`의 상수로 두고, CSS 토큰과 값이 같은지 단위 테스트로 확인한다.

### 2.5 글꼴

- **UI 글꼴:** Pretendard Variable(OFL-1.1)을 npm 패키지 `pretendard`로 **직접 호스팅**한다(동적 서브셋). 외부 CDN을 부르지 않으므로 TRD의 "서드파티 런타임 요청 없음"과 충돌하지 않는다. (D10)
- **캔버스 글꼴(출력물)은 이번 개선 범위가 아니다.** 바꾸면 내보낸 PNG가 달라지므로 별도 Idea로 다룬다.

## 5. 남은 것
