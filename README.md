# Somenail — 썸네일 스튜디오

> 배경색을 바꾸고, 이미지를 올리고, 글자를 쓰면 끝.

**Somenail**은 로그인·백엔드·AI 없이 브라우저에서 썸네일을 빠르게 만드는 무료 정적 웹앱입니다. 별도의 파일 업로드 서버를 사용하지 않고, 사진은 사용자의 브라우저에서만 처리합니다.

## 실행하기

**Node.js 20.19+ 또는 22.12+** 환경이 필요합니다.

    npm install
    npm run dev

개발 서버가 안내하는 로컬 주소를 브라우저에서 엽니다.

    npm run build
    npm run preview

타입 검사와 빌드를 함께 실행합니다.

    npm test

컬러 및 이미지 배치/레이어 순서에 대한 단위 테스트가 포함되어 있습니다.

## MVP 기능

| 영역 | 기능 |
| --- | --- |
| 배경 | 6가지 추천 색상, 색상 선택기, HEX 입력 |
| 이미지 | 로컬 PNG/JPG/WebP 업로드(20MB 이하), 여러 장 배치, 드래그, 비율 유지 크기 조절 |
| 텍스트 | 여러 줄 작성, 색상·글꼴·굵기·정렬·크기·위치 변경 |
| 레이어 | 선택, 앞뒤 순서 변경, 삭제, Delete/Backspace 단축키 |
| 출력 | **1280×720 PNG** 다운로드, 워터마크·선택 테두리 미포함 |
| 레이아웃 | 반응형 캔버스, 파일 드롭 지원 |

### 사용 순서

1. 왼쪽에서 **배경색**을 바꿉니다.
2. **이미지 업로드**로 로컬 파일을 추가합니다(또는 캔버스 영역에 드롭).
3. **텍스트 추가하기**를 누르고 내용을 수정합니다.
4. 캔버스에서 요소를 드래그하고 모서리 핸들로 크기를 바꿉니다. 선택된 요소는 속성 패널에서 편집할 수 있습니다.
5. 상단 **PNG 다운로드**를 누릅니다.

**주의:** MVP에서는 작업 내용이 브라우저 메모리에만 있으며 새로고침하면 사라집니다. 프로젝트 파일 저장/불러오기는 추후 검토합니다.

## 기술 구조

- React + TypeScript + Vite
- Konva + react-konva: 캔버스, 드래그, Transformer, PNG 출력
- File/Blob API: 사용자 컴퓨터의 이미지를 서버 전송 없이 디코딩하고 URL을 관리
- 브라우저 자체 Canvas 기반 이미지 합성
- 파일 업로드용 서버, DB, 로그인, 외부 AI API **없음**

정적 배포는 빌드된 dist/ 폴더만 호스팅하면 됩니다. 상대 경로 자산 설정을 적용해 GitHub Pages 저장소 하위 경로와 Vercel 정적 호스팅에 대응합니다. **배포 자동화와 운영 도메인은 아직 구성하지 않았습니다.**

## 검증 체크리스트

- [ ] 배경색을 변경한 후 PNG에 동일한 색상 반영
- [ ] PNG/JPEG/WebP 각 파일이 보이고 드래그·크기 조절 가능
- [ ] 2개 이상 요소를 추가하고 앞/뒤 이동, 삭제
- [ ] 한글 여러 줄 텍스트의 서식과 내보내기 일치
- [ ] 선택 테두리가 PNG에 포함되지 않음
- [ ] 출력된 PNG 파일 해상도가 정확히 1280×720
- [ ] 불량 이미지·20MB 초과 파일·잘못된 HEX 입력 시 안전한 안내
- [ ] DevTools Network에서 사용자 이미지 업로드 요청이 없음
- [ ] Chrome/Edge/Safari에서 화면 축소, 파일 업로드, PNG 다운로드 동작

위 항목은 **사람이 브라우저에서 확인할 수 있도록 만든 인수 체크리스트**이며, 모두 통과했다는 의미는 아닙니다.

템플릿 갤러리, AI 생성·배경 제거, 외부 이미지 검색, 계정, 서버 저장, 프로젝트 JSON 저장, 실행 취소/다시 실행, 다중 출력 비율, 자동 SNS 게시, 복잡한 그래픽 요소는 초기 버전 범위가 아닙니다.
