# Somenail (썸네일)

> 배경색을 바꾸고, 이미지를 올리고, 글자를 쓰면 끝.

**Somenail**은 설치와 로그인 없이 웹 브라우저에서 간단한 썸네일 이미지를 만드는 초경량 편집기입니다. Canva와 같은 범용 디자인 플랫폼이 아닌, **한 화면에서 빠르게 편집하고 바로 PNG로 저장하는 경험**을 목표로 합니다.

- **서버리스:** 백엔드·데이터베이스·계정 시스템 없이 정적 웹앱으로 동작
- **로컬 편집:** 업로드한 사진을 별도 서버로 보내지 않고 브라우저 메모리에서 처리
- **최소한의 기능:** 배경색, 이미지 오브젝트, 텍스트의 세 가지 편집 요소에 집중
- **즉시 다운로드:** 결과물에 워터마크 없이 PNG 내보내기

## 제품 범위 (MVP)

| 영역 | MVP 기능 |
| --- | --- |
| 캔버스 | 1280 × 720 (16:9), 초기 배경색 지정 |
| 배경 | 컬러 피커 및 HEX 입력, 실시간 반영 |
| 이미지 오브젝트 | 로컬 PNG/JPEG/WebP 추가, 선택·이동·크기 조절·삭제 |
| 텍스트 | 입력·수정, 줄바꿈, 글꼴 크기·굵기·색상·정렬, 이동·삭제 |
| 편집 | 여러 이미지/텍스트 요소 배치, 선택된 요소에 대한 간단한 속성 편집 |
| 내보내기 | 원본 크기의 PNG 파일 다운로드 |

### 이번 버전에 포함하지 않는 것

템플릿 갤러리, AI 생성·자동 배경 제거, 온라인 이미지 검색, 계정/로그인, 클라우드 저장, 협업, 프로젝트 파일 저장, SNS 게시 자동화, 서버 API, 분석 스크립트는 MVP 범위에서 제외합니다. 필요성은 실제 사용 후 판단합니다.

## 사용 흐름

1. 페이지를 열면 빈 16:9 캔버스가 나타납니다.
2. 배경색을 지정합니다.
3. 원하는 이미지(오브젝트)를 업로드하여 위치와 크기를 조정합니다.
4. 텍스트를 입력하고 스타일을 변경합니다.
5. **PNG 다운로드**를 누르면 브라우저에서 결과물을 저장합니다.

## 구현 방향

- **프런트엔드:** React + TypeScript + Vite
- **캔버스 렌더링/상호작용:** Konva + react-konva
- **파일 처리:** 브라우저 File API, Object URL, Canvas 기반 PNG 내보내기
- **배포:** GitHub Pages 또는 Vercel 정적 사이트 (백엔드 런타임 불필요)

코드 및 개발 환경은 추후 구현 단계에서 추가합니다. 현재 저장소는 **제품/기술 요구사항을 정리하는 초기 단계**이며, 앱 실행·배포는 아직 지원하지 않습니다.
